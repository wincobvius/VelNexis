Your inkjet prints have missing lines, banding, or colors that drop out — the classic clogged print head. Heads clog when ink dries in the tiny nozzles, especially in rarely-used printers. The correct cleaning method uses the printer's own maintenance cycle; the wrong method (alcohol, tissues, poking) kills heads permanently.

## How to fix it

1. Use the printer's own menu: Settings → Maintenance → Head Cleaning (do not open the printer and rub the head).
2. Run cleaning, print a nozzle check, compare the pattern.
3. If gaps remain, run cleaning once more — 2–3 times maximum.
4. Then wait a few hours (deep clogs dissolve slowly) and test again.
5. If heads stay clogged after that, a service shop does a manual cleaning — do not use alcohol on modern heads.

## Clean heads the right way
- Always start with the printer's own cleaning cycle from its software or menu - never touch the nozzles by hand.
- Run up to 3 cycles maximum, printing a test page after each. Cleaning uses ink, so stop as soon as lines look solid.
- For cartridges with copper contacts, wipe only the contacts with a dry lint-free cloth. The nozzle plate gets cleaned by the machine.
- If lines are still missing after 3 cycles, leave the printer switched on for a few hours - warm ink slowly dissolves dried blockages - then run one more cycle.
- Dust inside the printer lands on the heads: keep the paper tray closed and cover the printer when unused.
- Heads that stay blocked for months may be permanently dried - a new cartridge is cheaper than any cleaning at that point.
