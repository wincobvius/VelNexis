You are switching browsers — Chrome to Edge, Firefox to Chrome — or moving to a new computer, and years of carefully saved bookmarks need to come along. Browsers speak a common language for this: the bookmark HTML file. Export once, import anywhere — and there is an even easier sync path for Chrome users.

## How to fix it

1. In the old browser, press Ctrl + Shift + O (bookmark manager) → export bookmarks as HTML file.
2. In the new browser, open bookmark manager → Import → choose that HTML file.
3. Chrome can also import directly: menu → Bookmarks → Import bookmarks and settings.
4. Sign in to Chrome with the same Google account on both PCs — bookmarks sync automatically.
5. Firefox also supports direct import from Chrome in one click.

## Move bookmarks in two minutes
- Chrome and Edge: menu > Bookmarks > Bookmark manager > menu > Export bookmarks. This saves one HTML file with everything inside.
- Open the other browser, use its Import option, and pick that HTML file. Folders and names come across exactly.
- If you sign in to the same account (Google or Microsoft), syncing is even easier - bookmarks follow the account, no file needed.
- Firefox: Library > Bookmarks > Export Bookmarks to HTML, then import in the other browser.
- On your phone, bookmarks sync automatically once the same account is signed in on both browsers.
- Keep the exported HTML file saved somewhere safe - it works as a free backup of every bookmark you own.

## Quick recap
- Export bookmarks to an HTML file from the old browser.
- Import the same file into the new one.
- Signed-in accounts sync without any file.
- Keep the HTML file - it is a free full backup.
