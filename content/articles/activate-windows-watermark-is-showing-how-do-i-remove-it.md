A see-through message sits in the corner of your screen: "Activate Windows — Go to Settings to activate Windows." It appears when Windows is not activated with a genuine license — maybe the PC never had a key, the key expired, or new hardware confused the activation. The watermark does not stop Windows from working, but it never goes away on its own.

## How to fix it

1. The real fix: buy a Windows license key and activate: Settings → System → Activation.
2. If you already had a license, click Troubleshoot in the Activation settings — it often re-activates.
3. If you changed hardware recently, sign in with the Microsoft account linked to the license.
4. Check the key: Command Prompt, type slmgr /xpr to see activation status.
5. Avoid unknown "activator" tools from the internet — most contain viruses.

## Deal with the watermark
- The watermark means one thing: Windows is not activated. Settings > System > Activation is where a genuine key goes.
- If this PC ran activated Windows before, run the Activation troubleshooter - digital licenses re-link to the hardware automatically.
- Changed parts? Signed in with a Microsoft account, the troubleshooter's 'I changed hardware recently' option restores the license.
- Watermark remover tools do not activate anything and often carry malware - and the watermark returns after every update.
- What actually changes without activation: a watermark and some personalization settings. Everything else works, including updates and security.
- The honest options: buy a license, live with the watermark, or use free Linux for basic needs.
- Very cheap online keys are gray market - they activate today and die next year, with no refund.
