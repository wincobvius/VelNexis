An app updated and the new version is worse for you — heavy, redesigned, or a feature you need was removed. You want the previous version back on your phone. Play Store never offers old versions, so this needs an APK from a careful source, plus one setting to stop the auto-updater from erasing your work.

## Step 1 — Get the old APK

1. **Find the version you want:** the app's Play Store page (in a browser) or APKMirror's version history shows the list of past versions with dates — match the one you were happy with (check "app version" in the app's About/Settings if you do not know the number).
2. **Download from a reputable archive** (APKMirror is the standard: original signatures, unmodified files) — the same source discipline as our safe-APK guide applies, doubled for old versions: the old build will not receive security patches, which is the honest cost of this whole maneuver.

## Step 2 — Install it over the new one

3. **Uninstall the current version** (you lose the app's settings and local data — export what it offers first), then install the old APK: allow "install unknown apps" for your file manager for the moment.
4. **Or install "over" without losing data:** installing an OLDER version over a newer one fails the signature/version check on most phones — the clean path is uninstall-first. (Advanced: ADB downgrades without data loss — a computer tool for confident users; fine to skip.)

## Step 3 — Stop the auto-updater

5. **Play Store → profile → Settings → Network preferences → Auto-update apps → "Don't auto-update apps"** (or keep auto on and disable it per-app: the app's Play Store page → three dots → uncheck "Enable auto-update").
6. **Expect the "update available" badge forever** — the cost of staying behind. If you update accidentally someday, repeat the process.

## The honest note

Old app versions miss security fixes and slowly break against new servers — this is a bridge (until an alternative app, or a better update arrives), not a permanent home. And if the new version broke something you depend on, tell the developer through the Play Store review and support email: enough user feedback genuinely reverses redesigns.
