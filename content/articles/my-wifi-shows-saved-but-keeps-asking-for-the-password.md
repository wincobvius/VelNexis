Your phone shows the WiFi as "Saved" or "Saved, secured", but it never actually connects — or it connects and then asks for the password again and again. This happens when the saved password is old or slightly wrong, the phone's random MAC address feature confuses the router, or the router is overloaded with devices. Deleting the saved network and connecting fresh fixes most cases.

## How to fix it

1. Forget the network, then connect again with the password.
2. Restart the phone and the router.
3. Check the password is fully correct, letter by letter.
4. Turn off "random MAC address" for this network in WiFi advanced settings, then reconnect.
5. If it still fails, the router may be full. Restart the router to clear old sessions.

## More fixes for this problem
- Open WiFi settings, tap 'Forget' on that network, then join again and type the password slowly. Wrong characters are the most common reason.
- Restart the router (unplug 30 seconds) and the phone. This clears the saved connection on both sides.
- Check the password on another device. If it connects there, the problem is your phone, not the router.
- Delete old saved networks you never use. Phones sometimes mix up saved settings when the list is long.
- On a laptop, update the WiFi driver from the manufacturer's website. Old drivers often fail to save passwords.
- If the router is very old, log in to it and change the security type to WPA2. Some old setups keep rejecting new devices.

Delete every saved network you do not use, then reconnect. A crowded saved-network list confuses some phones into re-authenticating the wrong profile, which presents exactly as this bug.
