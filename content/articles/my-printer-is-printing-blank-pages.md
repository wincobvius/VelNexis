The printer runs through all its noises, feeds the paper — and delivers it completely blank. Ink or toner is being spent (maybe), paper is being used, and nothing appears. Blank pages come from empty cartridges, protective tape left on new cartridges, clogged print heads, or dried ink. The nozzle check reveals which one it is.

## How to fix it

1. Check ink levels — empty cartridges print blank.
2. Run a nozzle/head cleaning from the printer's maintenance menu, then test.
3. If new cartridge, remove the protective tape on it (people forget this often).
4. Print a test page. If colors missing, clean heads 2–3 times.
5. If cleaning does not fix it, the print head may be dried — deep cleaning or a service is needed.

## Fix blank pages step by step
- Run the printer's own 'Clean Print Heads' tool from its software or menu. Print a test page after each run.
- Take the cartridge out and check you removed the small orange tape or plastic cover from the nozzles. This is the number one cause of new cartridges printing nothing.
- Check ink levels in the printer software, and look for any error message - an error can stop ink flow even with a full cartridge.
- If the printer sat unused for weeks, ink has dried in the nozzles. Run 2 to 3 cleaning cycles with a test page between each.
- Reinstall the printer driver: remove the printer in Settings, restart, and add it again.
- Print a nozzle check pattern if your model has it. Missing lines tell you exactly which color is blocked.

Print one test page directly from the printer's own menu, not from the computer. If that page is blank too, the computer is innocent and the problem lives inside the printer or cartridge.

Different printer types fail differently. This table matches what you are seeing to the likely cause and the move that fixes it fastest.

## Inkjet or laser: what blank pages usually mean

| Sign | Inkjet | Laser |
| Fading after weeks unused | Dried nozzles - run cleaning cycles | Toner still fine - print a test page |
| Blank right after new cartridge | Tape left on nozzles, air bubbles | Shipping seal not removed, or dead drum |
| Streaks but text visible | One blocked color nozzle | Worn drum unit or low toner |
| Blank from the printer's own menu test | Cartridge electrical contacts dirty | Drum or toner problem, not your computer |
