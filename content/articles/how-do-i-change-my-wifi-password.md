You want a new WiFi password — maybe too many people know the old one, a guest used it, or you read that the default password is not safe. The WiFi password lives inside the router's settings page, which opens in any browser. The only things you need are the router's admin login (printed on the router itself) and two minutes.

## Step by step

1. **Connect to the router:** on a phone or computer connected to YOUR WiFi (or better, a cable), open a browser and type the router's address — **192.168.1.1** or 192.168.0.1 (the exact one, plus the admin username/password, is printed on the sticker under the router).
2. **Log in** with the sticker's credentials. If someone changed the admin password and nobody knows it, that is its own problem — see our Wi-Fi-taken-over guide for the reset-button route.
3. **Find the wireless settings:** look for "Wireless", "WLAN" or "WiFi" in the menu. You will see the network name (SSID) and the password field — often labeled "Pre-shared Key", "WPA key" or "Passphrase".
4. **Set the new password well:** WPA2 or WPA3 security mode (never "WEP" or "Open"), and a password that is long rather than clever — four random words beat a short scrambled one, and guests can type it.
5. **Save, then reconnect everything.** Every device drops instantly; reconnect each one with the new password. Do the important ones first — the one you are reading this on included.

## While you are in there

Change the ADMIN password too if it is still the sticker default (usually "admin/admin"). The WiFi password keeps neighbors off your internet; the admin password keeps strangers out of the router itself — and the second one is more dangerous than the first.
