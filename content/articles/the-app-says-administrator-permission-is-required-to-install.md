You run an installer and Windows stops it: "You'll need to provide administrator permission" — asking for an admin password you may not have. This happens on family PCs (you use a standard account), office computers (IT locks installs), or when installers are not run properly. There is a right way through, and reasons why sometimes the door should stay closed.

## How to fix it

1. Right click the setup file → Run as administrator.
2. Ask the PC's main user (the admin account holder) to type the admin password once.
3. If it is your office computer, IT staff block installs on purpose — ask them.
4. Check your account type: Settings → Accounts — if it says "Standard user", that is why.
5. Never bypass this with unknown tools — it exists to stop harmful software.

## Install without the error
- Right-click the installer and choose 'Run as administrator' - this alone clears most cases.
- If your account is not an admin, log in to the administrator account (usually the first account made on the PC) and install from there.
- To make your account an admin: the admin changes it in Settings > Accounts > Other users > change account type.
- Blocked even as admin? On the blue 'Windows protected your PC' screen, click 'More info' > 'Run anyway' - only for software you downloaded from its official site.
- Antivirus can block installers with the same message - pause protection briefly and retry.
- The long-term fix: never use a guest or limited account for daily work on your own PC.

Right-click and 'Run as administrator' is not a privilege escalation hack - it is how Windows asks the installer to confirm it may write system files. For software from an official source, it is safe and normal.
