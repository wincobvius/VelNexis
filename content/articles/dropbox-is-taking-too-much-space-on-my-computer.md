Your computer's disk is filling up, and the culprit is the Dropbox folder — a full copy of everything in your cloud storage now lives on the PC too. That is Dropbox's default behavior. The modern fix is "online-only" files: the folder shows everything, but files only download when opened. Big collections stop eating the disk.

## Freeing the space

1. **Right-click a folder inside the Dropbox folder → "Make online-only"** (the wording varies slightly by version). The folder's contents stay visible in Explorer/Finder, but the actual files are removed from the disk and live in the cloud. Opening a file downloads it on demand — a few seconds' wait, then it works normally.
2. **Do it folder by folder, biggest first.** Your Photos or Videos folders usually dwarf everything else; a single right-click on each recovers most of the space in a minute.
3. **Keep truly working files "available offline"** — anything you edit without reliable internet (Settings → Sync → make default online-only or per-folder as you prefer).

## The settings that stop it refilling

4. New files you create on the PC still download to the PC. If a shared folder is a firehose (team drive, camera uploads), make it online-only after every big addition — or set Dropbox's default for new content in Preferences → Sync.

## One caution

Online-only files need internet to open. If you travel or work offline, mark those folders available offline BEFORE losing the connection — the cloud cannot deliver a file to a PC with no signal.

((ad))

Dropbox's selective sync is the quiet fix: right-click the Dropbox icon > preferences > sync, and untick the huge folders you rarely open. They stay in the cloud, your drive gets its space back, and nothing is deleted.
