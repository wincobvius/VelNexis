Every link you click opens in Edge (or Safari, or another browser) instead of the browser you like. Windows and phones each have a "default browser" setting that decides this, and changing it takes a minute once you know where the switch lives on each system.

## Windows 11

1. **Settings → Apps → Default apps** → find and click **Google Chrome** in the list.
2. **Click "Set default"** at the top (the button that makes Chrome default for HTML, HTTP/HTTPS and PDF). Windows may ask to confirm switching away from Edge — confirm.
3. **The Microsoft-ask-me-again trap:** after Windows updates, you may see "Make Edge your default" prompts — close them once and they stop nagging.

## Windows 10

4. Settings → Apps → Default apps → Web browser → click the current one → choose Chrome. One click, done.

## On Android

5. **Settings → Apps → Default apps → Browser app** → Chrome. (On some Samsung/Xiaomi layers: Settings → Apps → three-dot menu → Default apps.) If Chrome is missing from the list, update it from the Play Store first — a not-updated Chrome sometimes hides from default lists.

## On iPhone

6. **Settings → Chrome → Default Browser App → Chrome.** Since iOS 14 this genuinely works — links from mail and messages open in Chrome.

## The verification

Click any link from an email or chat afterwards. If it still opens in the old browser, the system default was changed but the LINK is a special protocol (e.g., an app's own link) — for normal web links, the new default now rules.

((ad))

On Windows, after changing the default browser, some links still open in Edge because Windows re-associates file types after updates. If that happens, redo the setting and untick the 'always check associations' prompt that quietly resets it.
