You press the power button, the Windows logo appears with a spinning circle, and then nothing — for hours. Or the PC restarts itself again and again at the same point. This is called a boot problem and happens after a failed update, a damaged system file, a failing hard drive, or a connected USB device confusing the startup. Windows has built-in repair tools for exactly this.

## How to fix it

1. Force restart: hold the power button 10 seconds, then turn it on again. Try this 2–3 times — Windows sometimes repairs itself.
2. If it fails, the repair screen will open. Choose "Startup Repair".
3. Unplug all USB devices (hard drives, printers) and restart. A bad USB device can block startup.
4. If you recently installed something, use "System Restore" from Advanced options.
5. If nothing works, use "Reset this PC" with "Keep my files".

## Get past the loading screen
- Wait once, properly - a big update screen can take 30 minutes or more on older PCs.
- Force shutdown (hold power 10 seconds), start again. Two failed attempts trigger Automatic Repair.
- At the Automatic Repair screen: Advanced options > Startup Repair.
- Still stuck? Advanced options > Safe Mode. There, uninstall the latest update or the newest driver - that is usually the cause.
- Unplug every USB device before booting - one faulty stick can hang the whole boot.
- Startup Settings also offers low-resolution mode to get in and fix display drivers.
- If Safe Mode fails too, boot from a Windows USB stick and run Startup Repair from there. Make one now - it is a lifesaver.

Unplug every USB device before the next boot - one failing stick can hang the entire startup sequence. It is the cheapest test in the whole checklist and it rescues a surprising number of 'dead' PCs.
