A note on order: if your PC is slow, start with the slow-computer guide before anything else — half of all Windows complaints trace back to one worn-out drive or one overloaded startup list. Save the reset for last; it fixes almost everything, but the guides here are arranged so you rarely need it. If two guides seem to fit your case, run the cheaper one first. Worth knowing: the update-failure and blue-screen guides overlap — if both apply to you, fix updates first, since a corrupted update queue causes crashes that look like hardware trouble. Most people who work through this section end up surprised by how much life a clean boot and an SSD upgrade bring back.
