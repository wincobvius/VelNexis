# 🧹 Humanize Checklist — Naye articles publish se pehle check karo

## Kaise use karo?
Naya article likh kar (admin panel ya AI se) publish karne se pehle:
1. Neeche wala **Part 1 prompt** copy karo → kisi bhi AI mein paste karo → apna article paste karo → rewritten version lo
2. Ya khud neeche wali list se jhanjhat-phat AI words check kar lo

---

## Part 1 — AI to Human Converter Prompt (copy-paste ready)

```
You are a senior content editor and humanization specialist. Rewrite AI-generated
tech blog content into 100% authentic human-written content.

TASK:
1. Read the AI-generated content provided
2. Identify ALL AI-specific patterns
3. Replace every AI pattern with natural, conversational human alternatives
4. Maintain original meaning, SEO value, and readability
5. Deliver ONLY the rewritten content, NO explanations

AI PATTERNS TO ELIMINATE:
- Stiff opening phrases and introductions
- Overused transition words (Furthermore, Moreover, Additionally...)
- Robotic vocabulary and buzzword combinations (leverage, utilize, seamless...)
- Formulaic sentence structures
- Pattern repetition and template-like closings
- Passive voice overuse
- Academic/formal machine-generated language

HUMANIZATION RULES:
- Use contractions (don't, it's, can't, won't, you're)
- Vary sentence length (short + long mix)
- Add personal touch and opinions where fitting
- Conversational transitions (okay, so, basically, honestly)
- Sound like a real tech enthusiast writing for friends
- Mix paragraph lengths naturally

OUTPUT: Only the rewritten content. No headers, no explanations.
Start directly with the content.

[PASTE YOUR ARTICLE HERE]
```

## Part 2 — Sab se common AI words (quick list)

| AI word | Likho yeh |
|---|---|
| Furthermore / Moreover / Additionally | Plus / Also / On top of that |
| Therefore / Hence / Thus / Consequently | So / That's why |
| However / Nevertheless / Nonetheless | But / Still / Though |
| In other words / To clarify | So basically / What I mean is |
| For instance / To illustrate | Like / Say / For example |
| leverage / utilize / implement | use / set up / do |
| optimize / streamline | improve / make better / simplify |
| comprehensive / robust / seamless | complete / solid / smooth |
| cutting-edge / state-of-the-art / revolutionary | latest / new / different |
| empower / harness / facilitate | help / use / make easier |
| deep dive / drill down / touch base / circle back | detailed look / look closer / talk / come back to |
| key takeaway / actionable / best practice | main point / useful tip / good way |
| It is worth noting / It should be noted | Look — / Keep in mind |
| In today's rapidly evolving landscape | Tech moves fast — / These days |
| In this comprehensive guide we will | In this post I'll walk you through |
| In conclusion / To sum up | Bas itna — / So the bottom line |
| crucial / pivotal / vital | big deal / key / important |

## Teeno signals jo article ko "AI lagne" dete hain:
1. Har paragraph ek jaisi lambi (2-3 line) — **mix karo, koi ek line ka bhi ho**
2. Har heading ke neeche bilkul same structure — **kabhi list, kabhi story, kabhi seedha point**
3. Contractions nahi (do not → don't, it is → it's) — **contractions use karo**
