I replaced the ink cartridge but the printer still shows empty

VAbdul Rafay
CS student & tech writer · Sep 4, 2026 · 2 min read ✅ Editor-reviewed📅 Published Sep 4, 2026

You installed a new cartridge and the printer stubbornly claims it is still empty — refusing to print or nagging constantly. This maddening loop comes from unseated cartridges, un-reset ink counters, dirty contact points, or copy cartridges that report levels inaccurately. The printer usually just needs to be told about the new cartridge.

How to fix it

  1. Remove the cartridge and reinstall it firmly until it clicks.
  2. Restart the printer — counters refresh after restart.
  3. Some printers ask "Is this a new cartridge?" — answer correctly so it resets the counter.
  4. Clean the cartridge's metal contact points and the printer's contacts with a dry cloth.
  5. Some copy cartridges report wrong levels — the printer may still print fine; ignore the level or use original cartridges.

Make the printer see the new cartridge

  • Take the cartridge out and put it back in until it clicks. A slightly loose cartridge reports as empty.
  • Check the contacts - the small copper spots on the cartridge and inside the printer. Wipe them gently with a dry lint-free cloth.
  • Restart the printer with the new cartridge inside. Some models only read the chip on a fresh start.
  • Confirm the cartridge number matches your exact printer model - printers look similar but use different numbers, and wrong ones often show as empty.
  • Refilled cartridges sometimes have dead chips. The chip is what reports ink level, and refillers cannot always reset it.
  • If the printer warns about 'non-genuine' ink, you can usually press OK to continue. That warning is normal with third-party cartridges.

Write the cartridge code on the printer's lid with a marker. The next time ink runs out mid-print, the exact code is sitting on the machine itself - no digging through drawers or ordering the wrong one.
