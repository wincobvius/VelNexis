Chrome Has Become Very Slow on My Computer

VAbdul Rafay
CS student & tech writer · Sep 9, 2026 · 2 min read ✅ Editor-reviewed📅 Published Sep 9, 2026

Chrome used to open instantly; now it takes forever — tabs load slowly, typing lags, switching tabs freezes. Chrome's famous weakness is memory: every tab and every extension lives in RAM, and over months, extensions and cache pile up until the browser crawls. The fix is a short cleanup routine that works on every computer.

How to fix it

  1. Close extra tabs — every tab uses memory.
  2. Remove unneeded extensions: Chrome menu → Extensions → remove.
  3. Clear cache: Settings → Privacy → Clear browsing data → Cached images.
  4. Update Chrome: menu → Help → About Chrome.
  5. Open Task Manager inside Chrome (Shift + Esc) to see which tab or extension is eating memory.
Is Chrome really heavier than other browsers?

Historically yes — each tab is its own process. It is better now, but 20 open tabs plus 15 extensions will slow any browser on any PC.

Speed Chrome back up

  • Too many open tabs is the top cause - bookmark instead of hoarding.
  • Open chrome://extensions, disable all, then re-enable one by one. One heavy extension slows the whole browser.
  • Clear the cache (Ctrl+Shift+Del, cached images, last 4 weeks) - keep passwords.
  • Toggle hardware acceleration in Settings > System - test on and off; every PC is different.
  • Chrome's own Task Manager (Shift+Esc) names the tab or extension eating CPU.
  • Turn off preloading in Settings > Performance on low-RAM PCs.
  • Heavy antivirus scanning every page crawls - Windows Defender's lighter touch often wins.

Quick recap

  • Close tab hoards - bookmarks exist for a reason.
  • Disable all extensions, then re-enable one by one.
  • Chrome's own Task Manager (Shift+Esc) names the thief.
  • Clear cache monthly, keep passwords.
