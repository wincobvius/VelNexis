How do I print on both sides of the paper

VAbdul Rafay
CS student & tech writer · Sep 2, 2026 · 2 min read ✅ Editor-reviewed📅 Published Sep 2, 2026

You need double-sided printing — to save paper, make a booklet, or match an office requirement — and you are unsure whether your printer supports it automatically. Printers split into two camps: auto-duplex (flips pages by itself) and manual (you flip the stack). Both paths start from the same print dialog.

How to fix it

  1. If your printer supports auto duplex: in the print dialog, choose "Print on both sides" / "Two-sided".
  2. If it does not support it: choose "Manually print on both sides" — the printer prints odd pages, then asks you to flip the stack.
  3. For flipping manually, print page 1, reinsert the paper, print page 2 — test with one sheet first to learn the correct facing.
  4. Use the same paper orientation for all sheets.
  5. Check "duplex unit" is enabled in printer properties if the option is missing.

Print on both sides

  • Check the specs for 'duplex' or 'double-sided' - many cheap printers are one-side only.
  • If yours supports it: print dialog > Preferences > 'Print on both sides' and choose book or tablet style.
  • Manual duplex: print odd pages first, flip the stack, print even pages. Test with 4 pages to learn your printer's flip direction.
  • Binding edge matters: long-edge for portrait pages, short-edge for landscape.
  • From a phone, use the printer's own app - the system print sheet often hides duplex options.
  • Duplex jams more - use fresh, flat paper.
  • Some legal and exam forms must be single-sided - check before saving paper.

Label your printer's flip direction once - a small sticky note saying 'reinsert printed side up, top edge first' saves the trial-and-error test print every single time guests or family use it.
