Someone changed my WiFi password, how do I get it back

VAbdul Rafay
CS student & tech writer · Aug 10, 2026 · 3 min read ✅ Editor-reviewed📅 Published Aug 10, 2026

The Wi-Fi password that worked for months suddenly does not — someone at home changed it and forgot to tell you, or a visiting technician reset it on the way out. Whatever happened, the fix lives in the same place: the router's own settings page. You do not need the Wi-Fi working to reach it — a cable gets you in.

Note: The last resort in this guide (the router's reset button) wipes all its settings — Wi-Fi name, password, everything. Every device in the house will need reconnecting, and the router set up again from its sticker.

Getting back in

  1. Ask around first. Someone at home knows the new password — a 30-second conversation beats 30 minutes of router menus.
  2. Connect a computer to the router with an Ethernet cable — this works regardless of Wi-Fi passwords. Plug the laptop directly into the router itself, not into a wall socket.
  3. Open the router's settings page: type 192.168.1.1 (or 192.168.0.1 — the exact address and default login are printed on the router's sticker) into the browser.
  4. Log in with the sticker's credentials. If the admin password was also changed and nobody knows it, jump to the last resort below.
  5. Set a new Wi-Fi password: look for Wireless / Wi-Fi settings → passphrase or pre-shared key. Save, then reconnect your devices with the new password.
  6. While you are in there, change the admin password from the default — it is what stops this from happening again, and it takes one minute.

Last resort: the reset button

A 10-30 second press of the recessed reset button (a paperclip job) restores factory settings. Afterwards, the sticker's defaults get you in, you set your own Wi-Fi name and passwords, and every device reconnects once.
