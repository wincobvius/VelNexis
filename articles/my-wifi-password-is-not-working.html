My WiFi password is not working

VAbdul Rafay
CS student & tech writer · Jul 24, 2026 · 2 min read ✅ Editor-reviewed📅 Published Jul 24, 2026

You type the WiFi password and the phone says "incorrect password" again and again, even though you are sure it is right. This happens because passwords are case sensitive (capital and small letters are different), people confuse the password with the PIN on the router sticker, someone changed the password, or the phone saved old wrong details. It is frustrating but has simple fixes.

How to fix it

  1. Check capital and small letters. Passwords are case sensitive.
  2. Check you are not typing the PIN code instead of the password.
  3. Look at the sticker on the router. Try that password.
  4. If someone changed it, open router settings (192.168.1.1) with a computer connected by cable and set a new password.
  5. As a last option, press the router reset button for 10 seconds. Note: this erases all router settings.

When the password gets rejected

  • Type it slowly with the password visible. The letters O and zero, capital I and small l mix up constantly.
  • Check the router sticker - many routers have separate passwords for the 2.4 GHz and 5 GHz networks.
  • Someone may have changed the password: log in to the router (192.168.1.1 with the admin password from the sticker) and check it under Wireless settings.
  • Restart the router, forget the network on your device, and rejoin.
  • Routers near their device limit refuse new logins - remove old devices from the router's list.
  • Old devices may not support WPA3 - set the router to WPA2/WPA3 mixed mode.
  • If the password works for everyone else but one device, update that device's WiFi driver or delete its saved profile.

Check for the space at the end - phones preserve it, routers reject it, and it is invisible on the sticker. Typing the password with 'show password' on catches this instantly.
