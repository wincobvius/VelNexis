An App Keeps Crashing — How to Fix It

VAbdul Rafay
CS student & tech writer · Sep 11, 2026 · 4 min read ✅ Editor-reviewed📅 Published Sep 11, 2026

One app keeps closing the moment it opens — or it works for a minute and then dies. When it is just one app misbehaving (everything else works fine), the cause is almost always local: a corrupted cache, a broken update, too little free memory, or a bug in the app's latest version. The fix list is short and works on Android and iPhone both.

How to fix it

Note: Some steps below reset settings or clear an app's data, so you may need to sign in again afterwards. Keep your passwords handy before you start.
  1. Restart the phone — boring, but it clears the stuck memory state that causes many one-off crashes.
  2. Clear the app's cache: Settings → Apps → [the app] → Storage → Clear cache. If it keeps crashing, tap Clear data too (you may need to log in again).
  3. Update the app — developers ship fixes for known crashes fast. If the crash started right after an update and no fix has come, uninstall and roll back or wait a few days.
  4. Free up RAM and storage: close background apps, and keep at least 10% storage free — apps crash when they cannot write temporary files.
  5. If nothing works, uninstall and reinstall the app completely. Still crashing on a fresh install? Then it is a bug in the app itself — report it and use the web version meanwhile.
Why does clearing cache fix so many crashes?

Apps store temporary files to load faster; when one of those files gets corrupted, the app reads garbage and dies. Clearing cache forces it to rebuild clean files — no data lost, no reinstall needed.

The app crashes only when I open a specific feature — what then?

That is a bug in that feature, not your phone. Report it from the app's help menu or Play Store listing — and check the reviews; if everyone has it, only the developer can fix it.
