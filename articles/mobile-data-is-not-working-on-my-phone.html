Mobile data is not working on my phone

VAbdul Rafay
CS student & tech writer · Aug 4, 2026 · 2 min read ✅ Editor-reviewed📅 Published Aug 4, 2026

The signal bars show full, but websites do not open and apps say "no internet" even though mobile data is on. This happens when airplane mode is on by mistake, the data package has ended, network settings are damaged, or the network itself is down in your area. Sometimes it happens after changing the SIM or after a software update. It is annoying but usually fixed in a few minutes.

How to fix it

  1. Check that mobile data is ON and airplane mode is OFF.
  2. Turn airplane mode on, wait 10 seconds, turn it off.
  3. Restart the phone.
  4. Check APN settings: Settings → Network → Access Point Names → Reset to default.
  5. Call your network company. Maybe your data package ended or their service is down.

Get mobile data working again

  • Toggle Airplane mode on for 10 seconds and off. This forces the phone to connect to the network fresh.
  • Check you have not crossed your data limit: Settings > Connections > Data usage. Many plans slow data to almost zero after the limit.
  • Reset the APN: Settings > Mobile networks > Access Point Names > Reset to default. Wrong APN settings block data completely.
  • Take the SIM out and put it back, then test the SIM in another phone. If data fails there too, the SIM or network is the problem - call your provider.
  • Run a full network reset (Settings > General management > Reset). You will need to rejoin WiFi networks after, but it fixes deep settings errors.
  • Check if data works in another area. One dead spot means a coverage problem, not a phone problem.

Note whether calls still work while data fails - if they do, the SIM and network are fine, and the problem sits in phone settings. If both die together, call the provider: that is a line or account issue.
