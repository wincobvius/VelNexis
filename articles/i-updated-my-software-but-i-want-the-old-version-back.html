I updated my software but I want the old version back

VAbdul Rafay
CS student & tech writer · Aug 18, 2026 · 2 min read ✅ Editor-reviewed📅 Published Aug 18, 2026

A program updated itself and you hate the new version — features moved, design changed, or something you need is gone. You want the previous version back. This is possible for most software, because makers keep old versions available; the two keys are finding the official old file and stopping the auto-updater from pulling you forward again.

How to fix it

  1. Uninstall the new version: Settings → Apps.
  2. Big software makers keep old versions on their official site — search "software name old version download official".
  3. Install the old version and turn OFF automatic updates in its settings.
  4. Before downgrading, back up your settings and files from the new version if the formats differ.
  5. Avoid random "old version" websites — many add viruses to installers.

Go back safely

  • Know the risk first: old versions miss security fixes. Only go back if the new version is truly unusable for you.
  • For built-in phone apps, uninstall the update (Android: Settings > Apps > [app] > Uninstall updates) - that returns the app to its first version.
  • For PC programs, get the old version from the maker's own website only. Random 'old version' sites often bundle malware with popular software.
  • Turn off auto-updates for that one app while you use the old version, or it updates itself again overnight.
  • Save your settings and files before downgrading. Some downgrades wipe app data.
  • If the new version only changed the look, give it two or three days first. Most 'it got worse' feelings settle once your hands learn the new layout.

Before downgrading, check if the problem is actually a setting the update changed - default apps, permissions, layouts. Ten minutes reviewing settings often saves the risk that a downgrade brings.
