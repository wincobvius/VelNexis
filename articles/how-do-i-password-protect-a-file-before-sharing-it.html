How do I password protect a file before sharing it

VAbdul Rafay
CS student & tech writer · Sep 3, 2026 · 2 min read ✅ Editor-reviewed📅 Published Sep 3, 2026

You must send a sensitive file — salary slips, ID documents, a private video — and want a second lock beyond the link. Password-protecting files puts the key in your hands: even if the file leaks, it stays locked. Every file type has a free way to do this, and one golden rule about how to deliver the password.

How to fix it

  1. For a folder of files: compress with 7-Zip and set a password (choose AES-256).
  2. For a PDF: use PDF24 or Adobe's free tools to add an open password.
  3. For Word/Excel: File → Info → Protect document → Encrypt with password.
  4. Send the password by a different channel (file by email, password by SMS/WhatsApp).
  5. Remember: if you forget the password, the file cannot be opened — write it somewhere safe.

Protect files before sharing

  • Rule one: sending the password on the same channel as the file defeats the purpose. Send the password by SMS or a phone call.
  • PDFs: free tools like PDF24 add a password to any PDF. Word and Excel: File > Info > Protect Document > Encrypt with Password.
  • Any files: 7-Zip (free) > Add to archive > set a password with AES-256 encryption.
  • Photos and videos: put them in a folder, zip it with a password, share the zip.
  • Google Drive links are open to anyone who has them - for sensitive files, share an encrypted zip instead of a raw link.
  • Never send CNIC or passport photos unprotected in groups - one forward leaks them forever.
  • Make the password easy to say on a call but hard to guess - two unrelated words plus numbers work well.
