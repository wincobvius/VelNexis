Chrome extensions are not working at all

VAbdul Rafay
CS student & tech writer · Aug 23, 2026 · 2 min read ✅ Editor-reviewed📅 Published Aug 23, 2026

Your extensions — ad blocker, translator, screenshot tool — stopped working: icons are grey, features do nothing, or they vanish from the toolbar. Extensions break after Chrome updates, when they conflict with each other, or when their sync gets confused. A short reset routine revives almost all of them.

The revival routine

  1. Update Chrome first (Settings → About Chrome — it updates on the spot). Extension breakage follows Chrome updates like weather follows clouds; extension developers then push their fix within days. An extension broken "for no reason" is usually waiting for its own update.
  2. Toggle each extension off and on: menu (three dots) → Extensions → Manage extensions → switch off, switch on. This restarts the extension cleanly and clears many grey-icon states.
  3. Check extensions are allowed at all: chrome://extensions — the site/master switch "Allow extensions from other stores" matters only for side-loaded ones; and if you are on a WORK computer, ask before assuming breakage — company policies genuinely disable extensions on purpose.
  4. Toolbar icon vanished? Click the puzzle-piece icon → pin the extension back. Updates sometimes unpin everything — the extension still works; it is just hidden.
  5. Still dead? Remove and reinstall the extension from the Chrome Web Store. Its settings return if Chrome sync carries them; otherwise set them up again once.

The conflict case

If extensions broke simultaneously after installing a new one, the newcomer is the suspect — disable it and re-enable the others one by one. Two ad blockers or two password managers in one browser will fight forever.

If every extension dies at once, the profile itself is usually broken - not the extensions. Create a fresh Chrome profile, sign in, and let extensions sync back. Two minutes, and it fixes what reinstalling Chrome often does not.
